这一条是项目栏目的示例文章，以当前博客为例。

## 项目介绍

使用 Astro 和 Fuwari 搭建的个人博客，用来整理学习笔记、记录想法和分享文章。

## 技术与功能

- 技术栈：Astro、Svelte、TypeScript、Tailwind CSS。
- Markdown 写作，支持文章分类、标签和归档。
- 明暗主题切换、全文搜索与 RSS 订阅。
- 通过 GitHub Actions 自动构建并发布到 GitHub Pages。
