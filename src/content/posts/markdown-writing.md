这是一篇**排版示例**。你可以参考这里的写法，也可以在发布正式内容前删除这篇文章。

## 标题与段落

文章标题由文件顶部的 `title` 指定。正文从二级标题开始写，有助于自动生成清晰的目录。

段落之间空一行。用 **加粗** 标记需要强调的内容，用 `行内代码` 表示命令、文件名或变量。

## 列表与引用

准备一篇文章时，可以先列出三个问题：

- 这篇文章要解释什么？
- 读者需要哪些背景信息？
- 哪个例子能让解释更具体？

> 写作也是整理思路的过程。先把问题说清楚，再逐步补足细节。

## 代码示例

代码围栏后写上语言名称，就能获得相应的语法高亮。

```ts
const site = {
  name: "ocarina",
  author: "oliver",
};

console.log(`你好，${site.name}！`);
```

## 表格与提示块

| 内容 | 建议用途 |
| --- | --- |
| 分类 | 划分较大的文章主题 |
| 标签 | 标记具体技术或关键词 |
| 摘要 | 在文章列表中说明这篇文章写了什么 |

:::tip
写完后检查标题层级、代码示例和链接。用手机宽度看一遍，通常还能发现一些桌面端不明显的排版问题。
:::

## 收尾检查

发布前读一遍开头和结尾：开头有没有说明问题，结尾有没有交代结果。如果都能回答，文章就有了基本的完整性。
